Firebase 混合推理测试

验证 Firebase JavaScript SDK 的端侧、云端与端侧优先路径。SDK 固定为 13.4.0，不加载 Analytics。

本页仅用于 localhost 开发。加载 Firebase SDK、App Check 验证及模型下载需要联网；“只测端侧”不向云端发送提示词。云端或可能回退到云端的测试需要单独同意。先使用非私人测试文本。

正在加载 Firebase SDK。

1. 测试 Firebase 端侧调用

本按钮使用 ONLY_ON_DEVICE；端侧失败时直接报错，不自动上传。

2. 配置并验证 App Check

  1. 按 F12 打开开发者工具，在 Console（控制台）中找到 Firebase 输出的 App Check debug token。
  2. 在 Firebase 控制台进入“安全 / App Check / 应用”，为本 Web 应用登记该 debug token。
  3. 回到这里点击“验证 App Check”。token 不用发给助手，也不要提交进仓库。

打开本项目的 App Check

本页使用 SDK 官方本地 debug 模式，不伪造验证结果。正式发布前需配置生产验证提供方，不能直接发布此调试页。

3. 测试云端与端侧优先

这里预填 SDK 13.4.0 的默认混合推理云端模型；是否已对项目开放、是否有免费额度，以 Firebase 控制台和实际请求为准。

端侧优先使用 PREFER_ON_DEVICE。端侧可用时通常仍走本地；只有日志真实返回 in_cloud 才能证明该次走了云端，不把仅本地成功当成回退成功。
